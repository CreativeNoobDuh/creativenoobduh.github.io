# CreativeNoobDuh Apps

Static GitHub Pages hub for CreativeNoobDuh apps and tools.

Current featured projects:

- Bandeja Score
- Padel Matchmaker
- Valentines Reminder

## Local preview

Open `index.html` in a browser, or serve this folder with any simple static file server.

## Publish

Push the contents of this repository to `CreativeNoobDuh/creativenoobduh.github.io` and GitHub Pages will serve the site at `https://creativenoobduh.github.io`.
